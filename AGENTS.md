# strata

Deterministic codebase index. See `README.md`.

## Agent skills

### Issue tracker

Issues and specs live as GitHub issues in `afshinator/strata`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Five canonical triage roles, label string equal to role name: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at the repo root, `docs/adr/` for decisions. `GLOSSARY.md` exists and is the source of truth for domain vocabulary; `docs/adr/` has no entries yet. See `docs/agents/domain.md`.
